ModelPilot Team Evaluation

Evaluation date 2026-11-12. Dataset modelpilot-challenge-v1, coding and extraction.

The same fixed synthetic prompts were captured through the ModelPilot provider SDK. Each model used a fresh text context, no tools and a 4096-output-token ceiling. An exact JSON grader compared the values against a predetermined answer key. Held-out cases were reserved for comparison.

Calibration scores are scoped to the verified model versions, runtime settings and observed input ranges in the JSON subscription. Six examples per task provide limited evidence. Results apply to this fixture suite. Transport failures are counted separately below. CNY amounts use conservative accounting and include uncertain reserves where applicable.
